# get-adc

Скрипты к занятию «Переход из аналогового мира в цифровой» (АЦП) платы **get-adc**:
8-битный АЦП на R2R-ЦАП и компараторе (блок **8-bit ADC**) и 10-битный АЦП
**MCP3021** на шине I2C (блок **12-bit ADC**, микросхема — 10-битная).

## Файлы и задания

| № | Задание | Файл |
| --- | --- | --- |
| 1 | 8-битный АЦП последовательного счёта | `r2r_adc.py` — класс `R2R_ADC`, метод `get_sc_voltage()` |
| 2 | График напряжений на входе АЦП ПС | `r2r-sc.py`, функция `adc_plot.plot_voltage_vs_time()` |
| 3 | Гистограмма периодов измерений АЦП ПС | `r2r-sc.py`, функция `adc_plot.plot_sampling_period_hist()` |
| 4 | 8-битный АЦП последовательного приближения | `r2r_adc.py` — метод `get_sar_voltage()` |
| 5 | График напряжений на входе АЦП ПП | `r2r-sar.py` |
| 6 | Гистограмма периодов измерений АЦП ПП | `r2r-sar.py` |
| 7 | 10-битный АЦП MCP3021 на шине I2C | `mcp3021_driver.py` — класс `MCP3021`, метод `get_voltage()` |
| 8 | График напряжений на входе АЦП на шине I2C | `mcp.py` |
| 9 | Гистограмма периодов измерений АЦП на шине I2C | `mcp.py` |
| 10 | Датчики температуры и освещённости | `mcp.py` (вход АЦП переключается перемычкой **ADC INPUT**) |

Номера GPIO, которые используются в коде (по шелкографии платы get-adc):

* ЦАП блока **8-bit ADC**: `bit7…bit0` → `GPIO 26, 20, 19, 16, 13, 12, 25, 11`
* Выход компаратора → `GPIO 21` (`1`, когда напряжение на входе DAC больше, чем на входе SIG — горит светодиод COMP)
* MCP3021 → I2C: `GPIO 2` — SDA, `GPIO 3` — SCL, адрес `0x4D`

## Подготовка малинки

1. Включить I2C: `sudo raspi-config` → `Interface Options` → `I2C` → `Enable`.
2. После каждой перезагрузки выставлять альтернативную функцию линиям I2C:
   ```bash
   raspi-gpio set 2 a0
   raspi-gpio set 3 a0
   raspi-gpio get          # у GPIO2 и GPIO3 должна быть функция a0
   i2cdetect -y 1          # в таблице должен появиться адрес 0x4D
   ```
3. Установить библиотеки:
   ```bash
   sudo apt install python3-matplotlib python3-smbus
   ```
4. Измерить мультиметром динамический диапазон и вписать своё значение в скрипты:
   * 8-битный АЦП — переменная `dynamic_range` в `r2r_adc.py`, `r2r-sc.py`, `r2r-sar.py`
     (напряжение между тест-поинтом **OUT** и **GND** при поданном на ЦАП числе 255):
     ```bash
     python3 -c "import r2r_adc; a = r2r_adc.R2R_ADC(3.3); a.number_to_dac(255); input('Замерьте OUT-GND и нажмите Enter'); a.deinit()"
     ```
   * MCP3021 — переменная `dynamic_range` в `mcp3021_driver.py`, `mcp.py`
     (напряжение между контактами **PWR** и **GND** блока AUX PWR при установленной перемычке 5V).

Все скрипты запускаются из папки `get-adc` (они импортируют файлы друг из друга):

```bash
cd get-adc
python3 r2r_adc.py            # если нет прав на GPIO: sudo python3 r2r_adc.py
```

## Проверка заданий

### Задание 1. 8-битный АЦП последовательного счёта

```bash
cd get-adc
python3 - <<'EOF'
import r2r_adc
adc = r2r_adc.R2R_ADC(3.293)
try:
    while True:
        print(f"Напряжение: {adc.get_sc_voltage():.3f} В")
finally:
    adc.deinit()
EOF
```

* Вращайте ручку потенциометра — на экране непрерывно печатается напряжение от ~0 до ~3.3 В.
* Сверьте выведенное значение с мультиметром на жёлтом тест-поинте выхода потенциометра: расхождение — единицы МЗР (МЗР ≈ 13 мВ при 3.293 В).
* Во время работы скрипта синие светодиоды `bit7…bit0` быстро перебирают числа на ЦАП, а светодиод COMP загорается на числе, ближайшем к измеряемому напряжению.
* Время одного преобразования растёт с напряжением: последовательному счёту нужно больше шагов (при `compare_time = 0.0001` — от долей миллисекунды при 0 В до нескольких десятков миллисекунд при 3.3 В).

### Задания 2 и 3. График и гистограмма АЦП последовательного счёта

```bash
python3 r2r-sc.py
```

* Печатается число сделанных измерений за `duration = 5` с, затем открывается окно с графиком напряжения.
* Медленно поверните ручку потенциометра во время измерения — линия на графике повторяет движение, значения по оси Y лежат в диапазоне 0…`dynamic_range`.
* Плоские участки и ступеньки размером ≈ 13 мВ — нормальное квантование 8-битного АЦП.
* Закройте первое окно — откроется гистограмма периодов измерений: столбики в диапазоне до 0.06 с. При большем напряжении на входе период больше, поэтому у последовательного счёта разброс периодов большой.

### Задание 4. 8-битный АЦП последовательного приближения

```bash
python3 r2r_adc.py
```

* Скрипт печатает напряжение методом `get_sar_voltage()`; значения совпадают с мультиметром в пределах единиц МЗР.
* Число шагов всегда ровно 8 (при любом напряжении), поэтому одно преобразование при `compare_time = 0.0001` занимает единицы миллисекунд.
* Запустите подряд `r2r-sc.py` и `r2r-sar.py` и сравните напечатанное число измерений: у последовательного приближения оно заметно больше.

### Задания 5 и 6. График и гистограмма АЦП последовательного приближения

```bash
python3 r2r-sar.py
```

* Проверяется так же, как задания 2–3: график напряжения и гистограмма периодов.
* Гистограмма получается узкой: каждое преобразование занимает одно и то же время (8 шагов). Сравните её с гистограммой из `r2r-sc.py`.

### Задание 7. 10-битный АЦП MCP3021 (шина I2C)

```bash
python3 mcp3021_driver.py     # предварительно raspi-gpio set 2 a0 и set 3 a0
```

* Раз в секунду печатается напряжение; сверьте с мультиметром на жёлтом тест-поинте входа АЦП (источник сигнала выбирается перемычкой **ADC INPUT**: потенциометр / датчик освещённости / датчик температуры).
* Поверните ручку потенциометра — значение меняется от ~0 до напряжения питания блока (при перемычке 5V — до ~5 В).
* Расхождение с мультиметром — единицы МЗР (МЗР ≈ 4.9 мВ при 5 В). Если расхождение больше, перемерьте `dynamic_range` между контактами **PWR** и **GND** блока AUX PWR.
* При `verbose=True` печатаются принятые по I2C байты и собранное из них число — удобно для проверки расшифровки протокола.

### Задания 8 и 9. График и гистограмма MCP3021

```bash
python3 mcp.py
```

* Печатается число измерений за `duration = 5` с, затем открываются график напряжения и гистограмма.
* Гистограмма получается самой узкой, а число измерений за 5 с — в разы больше, чем у 8-битных АЦП: одно измерение по I2C занимает десятые доли миллисекунды.
* Поверните ручку потенциометра во время измерения — линия на графике повторяет движение.

### Задание 10. Датчики температуры и освещённости

```bash
python3 mcp.py
```

1. Перемычкой **ADC INPUT** подключите вход MCP3021 к терморезистору, запустите скрипт и прижмите палец к терморезистору — на графике появится заметный участок изменения напряжения.
2. Перемычкой подключите фоторезистор, запустите скрипт и подносите/убирайте фонарик телефона — напряжение на графике растёт и падает вслед за освещённостью.
3. Достаточно показать два характерных участка на графике (нагрев и освещение); при необходимости увеличьте `duration`, чтобы удобнее было воздействовать на датчик.

## Если что-то не работает

| Симптом | Причина / решение |
| --- | --- |
| `RuntimeWarning: This channel is already in use` | GPIO не очистились после аварийного завершения скрипта — перезагрузите малинку |
| `PermissionError` при запуске | запускать с `sudo` или от пользователя с доступом к `/dev/gpiomem` |
| `ModuleNotFoundError: matplotlib` | `sudo apt install python3-matplotlib` |
| `ModuleNotFoundError: smbus` | `sudo apt install python3-smbus` |
| `i2cdetect -y 1` не видит `0x4D` | не выполнены `raspi-gpio set 2 a0` / `set 3 a0` или в `raspi-config` не включён I2C |
| Напряжение на экране заметно отличается от мультиметра | неверный `dynamic_range` — измерьте его на своей плате и впишите в скрипт |
| Гистограмма пустая | период измерений больше `plt.xlim(0, 0.06)` — уменьшите `compare_time` (например, до `0.0001`) |
| Измерения «дрожат» | `compare_time` слишком мал для компаратора — увеличьте его (например, до `0.001`) |
